ML PIPELINE STAGES
1

DATA COLLECTION & INGESTION

Network flows captured via NetFlow/IPFIX. Compatible with CIC-DDoS2019, NSL-KDD, and custom datasets. Supports live pcap ingestion.

2

PREPROCESSING & CLEANING

Removal of NaN/Inf values, duplicate elimination, and normalization using StandardScaler. Class imbalance handled via stratified sampling.

3

FEATURE ENGINEERING

40+ raw features → top-20 selected via SelectKBest (ANOVA F-test). Includes flow duration, packet rates, byte counts, IAT statistics.

4

MODEL TRAINING & SELECTION

8 classifiers trained with 5-fold cross-validation. Best performers: Random Forest, Gradient Boosting, MLP Neural Network.

5

ENSEMBLE VOTING CLASSIFIER

Soft-voting ensemble of RF + GBM + MLP achieves 99.3% F1-score. Model persistence via joblib for sub-millisecond inference.

6

REAL-TIME DEPLOYMENT

Prediction pipeline processes flows at <2.1ms average latency. Outputs attack type, confidence score, and mitigation recommendation.
